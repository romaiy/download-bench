# download-bench

Консольный скрипт на Node.js: последовательно скачивает указанный URL
**10 раз**, каждый раз дочитывая ответ до конца, и печатает среднее время
запроса, суммарный объём и скорость скачивания.

- Зависимостей **нет** - только стандартная библиотека Node.js.
- На диск ничего не пишется: тело ответа читается в память и сразу
  отбрасывается, считаются только байты.
- Один файл: `src/index.js`.

## Требования

- **Node.js 20+**. Минимум, на котором проверено - 18.
- Доступ в интернет к целевому хосту.

## Установка

Зависимостей нет, поэтому `npm install` не требуется. Достаточно склонировать
репозиторий.

## Запуск

### Через `npm start` (рекомендуется)

```bash
npm start -- https://i.pinimg.com/736x/b3/de/74/b3de749e268e05d20defb74b20d44fa4.jpg
```

### Напрямую через `node`

```bash
node src/index.js https://i.pinimg.com/736x/b3/de/74/b3de749e268e05d20defb74b20d44fa4.jpg
```

Схему `https://` можно опустить - она подставится автоматически:

```bash
node src/index.js i.pinimg.com/736x/b3/de/74/b3de749e268e05d20defb74b20d44fa4.jpg
```

## Метрики и единицы измерения

| Метрика             | Как считается                                                                                        | Единицы                |
| ------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------- |
| Время запроса       | wall-clock от старта запроса до получения последнего байта тела ответа (включая DNS, TCP, TLS, TTFB) | мс / с                 |
| Среднее время       | среднее арифметическое времён **успешных** запросов                                                  | мс / с                 |
| Объём               | сумма фактически принятых байт тела ответа по успешным запросам                                      | B; KiB / MiB / GiB     |
| Скорость скачивания | суммарный объём ÷ суммарное время запросов                                                           | **MiB/s** и **Mbit/s** |

Пояснения по единицам:

- **KiB / MiB / GiB** — двоичные единицы: `1 KiB = 1024 Б`,
  `1 MiB = 1024 × 1024 = 1 048 576 Б`.
- **Mbit/s** — десятичная единица: `1 Mbit = 1 000 000` бит.
- Скорость считается по **сумме времён самих запросов**, без учёта пауз
  между итерациями и вывода в консоль. Общее время работы скрипта
  дополнительно печатается в скобках отдельной строкой.
- Байты в таблице объёма - это байты **тела** ответа; заголовки HTTP
  не учитываются (для тяжёлых файлов это пренебрежимо мало, для
  крошечных ответов может исказить картину).

## Код возврата

| Код | Значение                                                           |
| --- | ------------------------------------------------------------------ |
| `0` | Скрипт отработал; хотя бы один запрос завершился успешно           |
| `1` | Нет аргумента, некорректный URL, либо **ни один** запрос не удался |
